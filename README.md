## ✨ Overview

**RazaToys** is a modern e‑commerce experience built for children and parents, inspired by joyful, colorful toy aesthetics with a cheerful color palette:
- **Sunshine Yellow (`#FFBD27`)**
- **Candy Pink (`#F35B9B`)**
- **Play Blue (`#279FE8`)**
- **Happy Green (`#79C942`)**
- **Play Purple (`#8C4EDB`)**
- **Warm Cream (`#FFF7EA`)**
- **Soft Black (`#17191F`)**

The platform pairs a playful, accessible shopping experience with a robust Laravel administration suite for managing products, categories, carousels, promotions, orders, and customer service.

---

## 🚀 Key Features

- **Toy-First Homepage**: Interactive hero carousel, shopping benefits bar, category exploration grid, promotional banners, age-group cards, and featured toy collections.
- **Unified Catalog & Shop**: Dynamic search, category filtering, price sliders, and clean sorting for toys and household essentials.
- **Streamlined Checkout**: Live cart updates, guest & authenticated checkout, delivery calculations, and instant order tracking.
- **Admin Dashboard**: Full product CRUD, category hierarchy, promotional carousel editor, customer inquiries, and order lifecycle management.
- **Ultra-Responsive**: Verified across 360px (mobile), 390px (iOS), 768px (tablet), 1366px (laptop), and 1920px (desktop).

---

## 🛠️ Technology Stack

- **Framework**: Laravel 11.x (PHP 8.2+)
- **Frontend / Reactivity**: Livewire 3.x, Alpine.js, Tailwind CSS, Vite
- **Database**: MySQL (utf8mb4_unicode_ci)
- **Styling**: RazaToys Custom Design System (`razatoys.min.css`)
- **Typography**: Fredoka & Inter (Google Fonts)

## ⚙️ Quick Start

```bash
# 1. Environment configuration
cp .env.example .env
php artisan key:generate

# 2. Database migration & setup
# Configure DB_DATABASE=razatoys in .env
php artisan migrate

# 3. Cache clearing
php artisan optimize:clear

# 4. Start local development server
php artisan serve --port=8008
```

Visit the website locally at [http://127.0.0.1:8008](http://127.0.0.1:8008).
